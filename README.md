# SHNL

Izvorni kod stranice [shnl.hr](https://shnl.hr): provjerene informacije o tome
gdje potražiti pomoć kod ovisnosti o kockanju u gradovima klubova SuperSport
HNL-a.

Svaki grad lige ima svoju stranicu s podacima javne zdravstvene ustanove u
kojoj se može zatražiti stručna pomoć: adresa, telefon i način naručivanja.
Podaci su prikupljeni sa službenih stranica ustanova.

## Pokretanje

```bash
npm install
npm run dev
```

## Provjere

```bash
npm run verify
```

Pokreće produkcijski build i sve testove.

## Tehnologije

Astro, TypeScript i Vitest. Stranica je potpuno statična, bez backenda.
